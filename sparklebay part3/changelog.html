Project Changelog

A summary of how the SparkleBay website grew from a basic set of pages into a responsive, interactive and search-friendly site.

How the site developed

Development stages
StageWhat was delivered
Part 1Proposal, wireframe, sitemap and a basic set of HTML pages.
Part 2Professional CSS, colour system, responsive layout, cards, sticky navigation and consistent pages.
Part 3Interactivity, dynamic content, validated forms, map, SEO, security and documentation.

Part 3 changes

Tabs on the About page, an animated FAQ accordion and a photo gallery lightbox on the Services page, scroll-reveal and hover animations built with CSS transitions and JavaScript, and an interactive Leaflet map on the Contact page with a 20 km service area and a distance check.

The Services price table is built by JavaScript from one list of services. Visitors can search, filter by category and sort by name or price. Booking and enquiry dropdowns use the same list so prices always match.

Enquiry form with an instant cost, time and availability estimate. Contact form that compiles a ready-to-send email. Booking form sent with AJAX. All three show clear error messages under each field.

Unique titles, descriptions and keywords, canonical links, structured data, descriptive image names and alt text, internal links, robots.txt and sitemap.xml.

Skip link, landmarks, ARIA, keyboard support, lazy images, deferred script, security headers, a spam honeypot and safe text handling in JavaScript.
